How this works

What you are looking at

Every row is one translation unit — a single string Weglot serves on the live site. The left column is the English source, the right is what visitors in this language see today. All of it is machine translation.

Every row leaves in one of two directions

  • Approve — the wording is right. The row joins the ready for CSV tray, which becomes the Weglot import file.
  • Edit — type the wording you want. Saving counts as approving, so the row joins the same tray with your text instead.
  • Re-translate — the wording is wrong and you would like the machine to try again. The row joins the re-translate tray.

A row can only be in one tray. Approving something you had queued takes it out of the re-translate tray, and vice versa — you never have to remember to undo the other one.

Working in bulk

Tick the box on any row, or the box in the header to take everything currently shown. A bar appears at the bottom with the same two actions applied to the whole selection. Filter first — Show: Needs review plus a search term, then select all — and a few hundred rows go quickly.

The trays are sent separately

Nothing leaves this screen on its own. Each tray has its own review screen where you can take rows back out, and its own confirmation. The re-translate tray goes to the machine as one batch; the CSV tray becomes a file you import into Weglot. Clicking a tray button repeatedly cannot send anything twice.

When the machine sends drafts back

Rows you queued come back marked needs your review, and that is where this page opens — you see what changed while you were away without looking for it. Each one shows the English, what is live today, and the new suggestion side by side, so you are never accepting something without seeing what it replaces. Accept takes it, Edit takes your wording instead, and Reject sends it back to be tried again — remembering what was refused, so you do not get the same suggestion twice.

Your decisions are kept in this browser

They apply instantly and survive a reload, but not a different computer. Download a backup writes them to a file you can keep. You never need to load anything back by hand — machine drafts arrive on their own.

Sending the batch and building the CSV are not wired up yet — the desk is being built before the machine translation is connected, so the review flow can be judged first.

Keyboard

J / K move between rows, A approves, R queues a re-translation, E edits, X ticks the box, Esc closes this box.
